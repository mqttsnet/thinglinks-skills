# 客户端接入与连通性自查

## 三步接入

1. **生成凭证** —— 控制台「个人中心 → MCP 凭证」新建,得到形如 `tl_mcp_xxxxxxxx` 的字符串。
   凭证与**本人 + 当前企业**绑定
2. **配置客户端** —— 直接用控制台给的现成配置(见下)。传输协议选 **Streamable HTTP**(不是 SSE),
   服务无状态,不需要会话保持
3. **验证** —— 发一次 `tools/list`,能列出工具即接入成功

请求头要同时接受 `application/json` 与 `text/event-stream`。

## 凭证不是「只能看一次」

明文随时可以在同一页面「查看」重新取到 —— 详情由单独接口下发,列表只给脱敏串。
所以**不要建议用户「丢了就重建一把」**,那会平白让还在用的客户端断掉。

- 脱敏串形如 `tl_mcp_...a3f9`,**保留的是尾部**:所有凭证头部都一样,只有尾部能把客户端里
  配的那串与列表里某一条对上。用户说不清用的是哪把时,让他比对尾部四位
- 签发后**有效期不可改**,能改的只有名称;停用/启用是单独动作,与删除不同 ——
  停用可恢复,删除不可
- 泄露的处置是**停用或删除那一把**,不是改它

## 配置形态有两种,别混用

控制台在「查看」时同时给出两种,照抄即可,**不要自己拼域名** —— 地址取自服务端配置,
开发态前端与网关不同端口,生产态域名也可能变。

**文件形态**(外层带 `mcpServers` 容器),整段粘进 `claude_desktop_config.json` 一类的配置文件:

```json
{
  "mcpServers": {
    "thinglinks": {
      "url": "https://<域名>/api/ai/mcp",
      "headers": { "Authorization": "Bearer tl_mcp_xxxxxxxx" }
    }
  }
}
```

**单条目形态**(只有服务器本身),给表单里一次只接受一个服务器的接入工具用:

```json
{
  "thinglinks": {
    "url": "https://<域名>/api/ai/mcp",
    "headers": { "Authorization": "Bearer tl_mcp_xxxxxxxx" }
  }
}
```

⚠️ 这类表单会把**最外层键**当作服务器名。把文件形态粘进去,条目会被命名成 `mcpServers` ——
**能连通,但名字是错的**,而且事后很难看出问题出在哪。

## 连不上时按这个顺序查

| 现象 | 多半是 |
| --- | --- |
| 连接失败、服务端日志干净 | 路径不对。对外 `/ai/mcp`,网关 `StripPrefix=1` 后服务侧 `/mcp`,三处常量要一致 |
| 401 且带 `WWW-Authenticate` | 凭证本身的问题:写错、已吊销、不属于当前企业 |
| 503 且带 `Retry-After` | 校验链路暂时不可用,不是凭证问题,**不要去重置一把有效的凭证** |
| 能连上但只看到两三个工具 | 客户端缓存了旧的工具清单,重连或重启客户端 |

401 与 503 分流是有意的:两者混在一起时,system 服务抖一下,用户会去重置一把完全有效的凭证。

## 连上了但数据不对:先查 `whoami`

比工具更靠前的一个自检端点:**`GET /ai/mcp/whoami`**,同一把凭证、同一条链路,
原样回显网关还原出来的身份 —— userId、employeeId、tenantId、当前公司/部门、
clientId、path,以及**切库结果 `dataBase`**。

这条链路上任一环出问题的表现都是「查出来的数据不对」而不是报错,所以症状是
「能连上、工具也能调、但查到的是别人的/空的」时,先打这个端点:

- `tenantId` 为空 → 凭证还原没落到上下文
- `dataBase` 为空 → 没拿到租户,后续任何查询都会打到默认库
- `clientId` 不是过滤器写死的那个 → 这次请求根本没走 MCP 凭证这条路

它挂在 `/mcp` 下是必要的而非随意:网关过滤器只拦 `/ai/mcp` 前缀,放在别处既不触发凭证校验,
也不在放行清单里。

与 `check_mcp_connection` 工具的分工:那个是走完整工具链路的自检,
`whoami` 是**更早一层**,直接看身份还原的结果。

## 客户端只缓存工具清单

无状态传输下动态增删工具不可靠 —— 客户端不会重新拉取。因此**不要用「没有某项数据就不注册这个工具」
的设计**:能力集必须在启动时确定,运行期是否有数据由返回值表达,不由工具的存在与否表达。
