# 数据没进目标库

桥接**有完整失败态**:成功 / 失败 / 部分成功 / 死信。不要套用规则执行那句「平台没有失败态」。

## 两个模式,顺序不能反

| 模式 | 传参 | 回答什么 |
| --- | --- | --- |
| 清单 | 不传追踪标识 | 这段时间失败了多少次、都是什么类型 |
| 单条 | 传追踪标识 | **卡在哪一步**(接入 → 规则匹配 → 限流 → 转换 → 发送) |

先用清单找到出问题的那一次,再拿追踪标识回看步骤。**「卡在哪一步」只有单条模式答得了。**

## 优先看死信

死信是重试都失败后进了死信通道的记录,是最该先看的一类。

## 设备标识为空是正常的

订阅源、测试发送、死信回放本来就没有设备,看触发来源说明,不要据此判断记录有问题。

## 结论

给出:失败次数与类型分布、典型一次卡在哪一步、失败原因。
本服务不能重放、不能改桥接配置。
