# 下发的命令没生效

本服务**不能下发命令**,只能查历史。用户要求下发时直接说明做不到。

## 顺序

1. `get_device_command_history` 看这台设备最近被下发过什么、什么时候发的
2. 看**设备有没有回应**:响应时间为空说明设备一直没回,这比命令状态本身更能说明问题
3. 设备没回应时,`get_device` 看连接状态与最后心跳 —— 离线设备收不到命令

## 三种情况

| 现象 | 含义 |
| --- | --- |
| 历史里根本没有这条命令 | 命令没发出去,问题在下发侧不在设备 |
| 有记录但设备没回应 | 命令发了、设备没收到或没处理,先看在线状态 |
| 有记录且设备回应了 | 命令链路是通的,「没生效」要去看业务侧效果 |

## 结论

给出:这条命令有没有记录、什么时候发的、设备回没回、当前连接状态。
要重新下发,请用户到控制台操作。
