# 登不上或整体不可用

**多人同时不可用先查到期,不要从账号查起。** 企业到期后全体成员登录被拒,
从单个账号入手会绕很久。

## 顺序

1. `get_my_tenant` —— 企业状态与到期时间。是否过期、还有几天,服务端已算好,不要自行比较日期
2. `list_my_applications` —— **应用到期时间独立于企业到期**,可能先失效,
   表现是「能登录但某个模块用不了」
3. `get_my_account` —— 单个账号的问题:密码是否过期、上次登录时间、账号状态
4. `get_my_login_history` —— 有没有失败的登录尝试、来源在哪

## 三种表现对应三个方向

| 表现 | 先查 |
| --- | --- |
| 全公司都登不上 | 企业到期 |
| 能登录但某个模块打不开 | 应用到期,其次是权限,见 [permission-denied](permission-denied.md) |
| 只有我登不上 | 账号状态与密码,再看登录记录 |

## 登录记录的读法

- 日期字段只有日期,精确时刻看创建时间
- 带截断标记时次数用总数,不要数返回的记录条数

## 结论

给出:企业与应用的到期时间、账号状态、最近失败登录的时间与来源。
本服务不能解锁账号、不能续期,处理请到控制台或联系管理员。
